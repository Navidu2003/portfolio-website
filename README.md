A modern, highly professional portfolio website built to showcase my experience, skills, and projects as an Artificial Intelligence & Machine Learning Intern and Python Developer.

## ✨ Features
- **Modern Glassmorphism Design:** Beautiful UI with semi-transparent elements and blurred backgrounds.
- **Dynamic Backgrounds:** Interactive glowing background that reacts to cursor movement.
- **Smooth Animations:** Elements fade in elegantly as you scroll using Intersection Observers.
- **Fully Responsive:** Optimized for both desktop and mobile viewing.
- **Semantic HTML5:** Structured clearly for accessibility and SEO.

## 💻 Local Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Navidu2003/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in any modern web browser to view the site locally. No build tools or servers are required!

## 🌐 How to Deploy to GitHub Pages
1. Create a new repository on GitHub (e.g., `portfolio`).
2. Upload these files to the repository.
3. Go to the repository **Settings**.
4. Navigate to **Pages** on the left sidebar.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/root` folder, then click **Save**.
7. In a few minutes, your site will be live!
